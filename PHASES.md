Each phase must be verified working (started, tested) before the next begins.

- [x] Phase 1 — Project setup: full directory skeleton, FastAPI boots, React boots, they talk to each other over the final API contract.
- [x] Phase 2 — Data collection structure: per-domain `sources.md`, download scripts, source manifests (no fabricated sources).
- [x] Phase 3 — Data processing: PDF/DOCX/TXT extraction, cleaning, legal structure detection (Act/Chapter/Section/Subsection/Clause), chunking (structured + generic fallback), metadata resolution (sidecar `.meta.json` or manifest match — never fabricated), schema validation.
