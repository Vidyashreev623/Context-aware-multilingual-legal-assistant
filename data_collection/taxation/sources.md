# Taxation Law — Sources

## Primary legislation
1. **Income-tax Act, 1961** — India Code — https://www.indiacode.nic.in/ — act — India (Central)
2. **Central Goods and Services Tax Act, 2017 (CGST)** — India Code — https://www.indiacode.nic.in/ — act — India (Central)
3. **Integrated Goods and Services Tax Act, 2017 (IGST)** — India Code — https://www.indiacode.nic.in/ — act — India (Central)
4. State GST Acts (e.g. Karnataka GST Act, 2017) — India Code (state acts section) — https://www.indiacode.nic.in/ — act — State-specific
5. **Customs Act, 1962** — India Code — https://www.indiacode.nic.in/ — act — India (Central)

## Case law / judgments
6. Supreme Court and High Court tax judgments — https://judgments.ecourts.gov.in/ — case — India (State/Supreme Court)
7. Income Tax Appellate Tribunal (ITAT) orders — source not independently verified in this pass; re-verify before adding.

## Notes
- The Income Tax Department's official portal (incometax.gov.in) was not independently verified in this collection pass; re-verify before treating it as a primary source for act text.
- GST has a Central + State dual structure — every GST document must be tagged with `central` vs `state` and the specific state where applicable.
