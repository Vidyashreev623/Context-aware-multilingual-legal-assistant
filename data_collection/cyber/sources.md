# Cyber Law — Sources

## Primary legislation
1. **Information Technology Act, 2000** (as amended by IT (Amendment) Act, 2008) — India Code — https://www.indiacode.nic.in/ — act — India (Central)
   - Ministry-hosted copy: Ministry of Electronics and IT (MeitY) — https://www.meity.gov.in/content/information-technology-act-2000
2. **Information Technology (Intermediary Guidelines and Digital Media Ethics Code) Rules, 2021** — MeitY — https://www.meity.gov.in/ — rules — India (Central)
3. **Information Technology Rules** (various, incl. reasonable security practices, CERT-In rules) — MeitY / India Code — rules — India (Central)

## Case law / judgments
4. Supreme Court judgments on cyber law (e.g. Section 66A matters) — https://main.sci.gov.in/judgments — case — India (Supreme Court)
5. High Court cyber-crime judgments — https://judgments.ecourts.gov.in/ — case — India (State)

## Notes
- MeitY (meity.gov.in) is the nodal ministry and was independently verified as the source for the IT Act text and rules.
- Do not collect from unofficial "legal explainer" blogs as primary text sources — quote/derive only from India Code or MeitY.
